# Advanced Customer Segmentation Using Machine Learning

## Project Overview

This project applies multiple unsupervised machine learning clustering algorithms to segment customers based on purchasing behavior, demographics, and engagement patterns.

The system performs customer behavioral analysis to identify meaningful customer groups that businesses can use for:

* Personalized marketing
* Customer retention
* Targeted promotions
* Business intelligence

---

## Machine Learning Algorithms Used

* K-Means Clustering
* DBSCAN
* Agglomerative Clustering
* Gaussian Mixture Model (GMM)
* OPTICS

---

## Features Implemented

* Data Cleaning
* Feature Engineering
* Feature Scaling
* Encoding Categorical Variables
* Elbow Method Optimization
* PCA Dimensionality Reduction
* Cluster Profiling
* Model Evaluation Metrics
* Pickle Model Saving

---

## Evaluation Metrics

The clustering algorithms were evaluated using:

* Silhouette Score
* Davies-Bouldin Index
* Calinski-Harabasz Score
